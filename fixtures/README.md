## corpus/ (Phase 1, in progress)

Generated by `node scripts/make-corpus.mjs` (needs the native build). `ninja-default` is the real export and its oracle is the XML's own `PlayerStat`/`MinionStat`. **Every other fixture is synthetic**: the ninja-default XML edited (Config stripped, a skill group swapped in, a tree node added or removed, an item mod line added), with the oracle taken from the native engine's recompute of the edited XML. Those are regression fixtures, not independent PoB desktop output. `manifest.json` lists the archetypes each one covers.
